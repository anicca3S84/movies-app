# 🎬 Movies App - Cinematic Discovery

> A modern Android application designed for movie enthusiasts to discover, search, and view detailed movie information. Built with clean MVVM architecture and RESTful API integration.

## 📱 Overview
**Movies App** demonstrates modern Android development practices. It provides a seamless experience for users to register accounts, explore trending movies, view cast details, and interact through comments and ratings.

## 🛠️ Tech Stack
This project leverages the latest Android technologies and Google's recommended architecture:
* **Language:** Kotlin 100%
* **Architecture:** MVVM (Model - View - ViewModel)
* **Networking:** Retrofit2 & Gson
* **Concurrency:** Coroutines & Flow
* **Image Loading:** Glide
* **Navigation:** Android Navigation Component
* **UI:** XML, ConstraintLayout, RecyclerView

## ✨ Key Features
1.  **User Authentication:** Secure Login, Registration, and Profile management.
2.  **Discovery:** Browse movies by categories (Trending, Popular, Now Playing).
3.  **Detailed Information:** Access movie synopses, trailers, and cast lists.
4.  **User Interaction:** Rate movies and leave comments.
5.  **Search:** Find movies easily by keywords.
